# Discriminator

## Overview

The Discriminator is one of the two fundamental neural networks in a Generative Adversarial Network (GAN). Its primary objective is to distinguish between real images sampled from the dataset and fake images generated by the Generator.

Unlike a conventional classifier, the Discriminator is not responsible for recognizing image classes such as Glioma, Meningioma, or Pituitary tumors. Instead, it learns whether an image belongs to the true data distribution or has been artificially generated.

Throughout training, the Generator and Discriminator compete against one another in an adversarial learning process. As the Generator improves its ability to synthesize realistic images, the Discriminator simultaneously becomes better at identifying generated images. This competition gradually improves the quality of reconstructed images.

---

# Why Do We Need a Discriminator?

Suppose the Generator is trained only with an L1 loss.

```
Healthy MRI
      │
      ▼
 Generator
      │
      ▼
Reconstructed MRI
```

The Generator only minimizes the pixel-wise difference.

Although the reconstruction may become numerically similar to the input, it often appears

- blurry,
- over-smoothed,
- lacking anatomical details.

This happens because L1 loss computes the average pixel error without considering image realism.

---

Adding a Discriminator changes the objective.

```
Healthy MRI
        │
        ▼
 Generator
        │
        ▼
Fake MRI
        │
        ▼
Discriminator
        │
        ▼
Real or Fake
```

Now the Generator must not only minimize reconstruction error but also produce images that appear realistic.

---

# Generator vs Discriminator

The Generator attempts to fool the Discriminator.

```
Generator

Input
 │
 ▼
Fake Image
```

The Discriminator attempts to detect fake images.

```
Real Image ───────►

                   Discriminator

Fake Image ───────►
```

Both networks improve together.

---

# Adversarial Learning

The Generator and Discriminator play a two-player minimax game.

```
Generator
     ▲
     │
     │
Discriminator
```

The Generator tries to minimize the probability that generated images are detected.

The Discriminator tries to maximize the probability of correctly identifying fake images.

This competition continues until generated images become indistinguishable from real images.

---

# Discriminator Input

During training, the Discriminator receives two different types of images.

## Real Images

```
Healthy MRI
```

These images come directly from the training dataset.

---

## Fake Images

```
Healthy MRI
      │
      ▼
Generator
      │
      ▼
Generated MRI
```

These images are synthesized by the Generator.

---

# Expected Outputs

For a real image

```
Real MRI

↓

Output ≈ 1
```

For a fake image

```
Generated MRI

↓

Output ≈ 0
```

The closer these outputs are to their target values, the better the Discriminator performs.

---

# Why PatchGAN Instead of a Standard CNN?

A conventional Discriminator predicts a single value.

```
MRI

↓

CNN

↓

Real
```

or

```
Fake
```

This approach evaluates the image globally.

However,

medical images contain extremely fine anatomical structures.

A global decision often ignores local inconsistencies.

---

PatchGAN solves this problem.

Instead of classifying the whole image,

it classifies many small image patches.

```
Input MRI

████████████████

↓

PatchGAN

↓

□ □ □ □
□ □ □ □
□ □ □ □
□ □ □ □
```

Each square represents the probability that a local image patch is real.

---

# Advantages of PatchGAN

Instead of evaluating only one decision,

PatchGAN verifies local image realism.

It checks

- tissue texture,
- edges,
- anatomical boundaries,
- local consistency.

This makes it particularly effective for medical image reconstruction.

---

# PatchGAN Architecture

The PatchGAN used in this project consists of multiple convolutional layers.

```
Input MRI
      │
Conv 64
      │
Conv 128
      │
Conv 256
      │
Conv 512
      │
1×1 Prediction Map
```

Each convolution gradually increases feature complexity while reducing spatial resolution.

The final layer produces a probability map rather than a single scalar value.

---

# Instance Normalization

Each convolution block uses

```
InstanceNorm2D
```

instead of Batch Normalization.

Instance Normalization is widely adopted in image generation tasks because

- it is less sensitive to batch size,
- improves style consistency,
- stabilizes GAN training.

---

# LeakyReLU Activation

The Discriminator uses

```
LeakyReLU
```

instead of ReLU.

Why?

ReLU completely suppresses negative activations.

```
Negative Values

↓

0
```

LeakyReLU preserves a small negative slope.

```
Negative Values

↓

Small Gradient
```

This prevents dead neurons and improves gradient flow during adversarial training.

---

# Training Procedure

For each training iteration

```
Healthy MRI

↓

Discriminator

↓

Real Prediction
```

and

```
Healthy MRI

↓

Generator

↓

Generated MRI

↓

Discriminator

↓

Fake Prediction
```

The Discriminator computes two losses

- Real Loss
- Fake Loss

Their average forms the final discriminator loss.

---

# Discriminator Loss

The discriminator is optimized using Binary Cross Entropy (BCE).

Real images should produce

```
1
```

Generated images should produce

```
0
```

The final discriminator loss is

```
Loss = (Real Loss + Fake Loss) / 2
```

This encourages accurate discrimination between authentic and generated samples.

---

# Relationship with the Generator

During every iteration

Step 1

```
Update Discriminator
```

Step 2

```
Freeze Discriminator
```

Step 3

```
Update Generator
```

The Generator receives gradients from the Discriminator and learns how to generate increasingly realistic MRI images.

---

# Role in Brain MRI Reconstruction

The Generator alone may produce blurry reconstructions.

The PatchGAN Discriminator encourages

- sharper brain boundaries,
- realistic gray matter textures,
- realistic white matter appearance,
- preservation of anatomical structures.

As a result,

the reconstructed healthy MRI becomes visually closer to a genuine healthy brain image.

---

# Role in This Project

The proposed reconstruction pipeline is

```
Healthy MRI
      │
      ▼
Generator
      │
      ▼
Generated Healthy MRI
      │
      ▼
PatchGAN Discriminator
      │
      ▼
Patch Probability Map
```

The Generator attempts to reconstruct anatomically plausible healthy MRIs.

The Discriminator evaluates whether the reconstructed images resemble real healthy brain MRIs.

Through adversarial learning, both networks improve simultaneously.

---

# Advantages

- Produces sharper reconstructions.
- Preserves anatomical structures.
- Improves local texture quality.
- Reduces over-smoothing.
- Stabilizes image generation.
- Encourages realistic MRI appearance.

---

# Limitations

- Requires additional GPU memory.
- Increases training time.
- Sensitive to learning rate imbalance.
- Can suffer from unstable adversarial training.
- May experience mode collapse if training is not properly balanced.

---

# Why PatchGAN Was Selected for This Project

This project aims to reconstruct healthy brain MRIs from images containing tumors.

The Generator must preserve healthy anatomical regions while correcting abnormal structures.

PatchGAN is particularly suitable because it evaluates local image realism rather than only global appearance.

This enables the Generator to reconstruct detailed anatomical structures with higher visual fidelity.
